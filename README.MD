# README

By no means am I a proper web developer, I am a photographer. That being said, I have been working on improving in that regard. Even so, there will be formatting problems, mainly in regards to the resizing of images at different aspect ratios with respect to the front site. As such, the best ratio to view the site will be 1920x1080. The back site, however, will not display well at any ratio below 1920x1080 as it is not made to scale to differing or mobile resolutions.
